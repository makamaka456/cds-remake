# 안드로이드 포팅 계획과 결정 기록

목표: 이 저장소의 PC 판(대항해시대3 리메이크, `CostaDelSol.Play` + `CdsHelper.Game`)을 거의 그대로 안드로이드로 옮긴다.
입력은 에뮬레이터처럼 원본 키보드 단축키를 유지한다(`docs/입력-설계.md`).

## 결정 (2026-10-31, 사용자)

| 항목 | 결정 |
|---|---|
| 화면 비율 | 메뉴에서 4:3 / 16:9 를 고른다 |
| 옮기는 순서 | 타이틀·불러오기 → 도시와 건물 → 바다 사건·조우 → 해전 → 상륙·탐험·발견물·이벤트 → 미니게임 → 모드·개발 창 |
| 배경음악 | APK 에 넣는다 (bgm-assets 릴리즈 Track02~29.mp3, 약 114MB → APK 약 200MB) |
| 세이브 | 「모든 파일 접근」 권한으로 `내장 저장소/CostaDelSol/` 에 PC 판과 같은 형식(`GameSave`) — 윈도우 `%APPDATA%\CdsHelper` 와 서로 옮겨 쓴다. 메뉴에서 폴더를 직접 고를 수 있다 |
| 커맨드 | 저장 · 불러오기 · 네비게이션(자동항해) 을 커맨드에 둔다 |
| 도구 앱 | Editor.exe(세이브 편집기, WPF 약 1만 2천 줄)는 나중에 필요한 화면만 |

## 크기 (실측)

| 자료 | 크기 |

| map-assets CDSX 19개(CITYCG 20MB, DISCOVER 9.4MB, DSTILL 5.6MB …) | 약 51MB |
| world.cdsx | 6.25MB |

CDSX 는 Ls12 로 이미 눌려 있어 APK 압축으로 더 줄지 않는다.

## 구조 메모

- 엔진(약 3만 7천 줄)은 원본 파일을 링크해 쓴다. WPF 가 섞인 자리는 원본에서 `#if !ANDROID` 로 가리고,
  자리가 필요한 것(`TableCache.FolderOverride`, `GameSave.FolderOverride`)은 PC 판에서 비워 두는 설정으로 둔다.
- 화면(UI, 약 5만 9천 줄 · 131개)은 WPF 라 다시 짓는다.
- PC 판은 대답을 기다리는 창(`ChoiceDialog.Ask` 등)을 429곳에서 쓴다. 안드로이드는 UI 스레드를 멈출 수 없으므로
  **게임 진행을 따로 된 스레드에서 돌리고, 창은 UI 스레드에 띄운 뒤 대답이 올 때까지 그 스레드만 기다리게** 한다 —
  진행 코드를 거의 그대로 옮길 수 있다.
- `Game`(엔진 중심 묶음)을 링크하면 41개 파일이 더 딸려 오고, 남는 걸림은 18곳이다:
  소리(`SoundBank`·`BgmPlayer` — WPF MediaPlayer/SoundPlayer), 그림(`ItemArt`·`TavernGuests` — BitmapSource),
  설정(`GameSettings`), Prism(`CityTable`), 그리고 `Disev`·`AccReplay` 묶음. 소리·그림·설정은 안드로이드 구현을 따로 둔다.

## 진행 (2026-11-01, 마을 묶음)

옮기는 방식: PC 판 시설 차림표(UI/Views/*Menu.cs)와 엔진은 **화면 물건을 짓지 않고 대화창만 부른다**.

## 진행 (2026-11-01, WpfLite — PC 판 화면 그대로)

PC 판 화면(WPF 를 코드로 지은 창 70여 개)을 **다시 짓지 않고 그대로 돌리려고** 작은 WPF(Wpf/ 폴더)를 지었다.
- 요소 나무 · 자리 잡기(Measure/Arrange) · 그리기(안드로이드 Canvas 로 그림 한 장) · 손(누름 · 끌기 · 마우스 올림 · 글쇠 · 길게 누르기 = 오른쪽 클릭) ·
  시계(DispatcherTimer) · 움직임(Animation) · 모달(DispatcherFrame = 게임 줄 Pump).
- 판 · 단추 · 그림 · 글 · 표(DataGrid) · 펼침 목록(→ 원본 고르기 창) · 글 칸(→ 기기 글자판) · 쪽지(Popup) · 동영상 칸(→ 판 위 TextureView, 원본 MP4).
- 띄운 창은 창 판(ChoicePanel)의 한 겹(WpfLayer)이다. 판(640x480)보다 큰 창(해전 800x600 · 개발 창)은 줄여 맞춘다.
- 「뒤로/ESC」 = ESC 글쇠, 안 받으면 오른쪽 클릭. 윈도 제목 줄이 있던 창(개발 · 편집)은 닫는다.

### 일부러 뺀 것(사용자 결정 · PC 전용)
- 툴바(마우스 조타 · 화면 따라가기 · 배로 · 리스본), Ctrl+클릭 배 놓기, Shift+우클릭 자동항해, 속도(kn) 표시.
- 메모리 스캐너 · 자동 플레이 · 이벤트 큐, 도구 앱 띄우기.
- 원본 PC 게임 세이브(바이너리) 편집기 — 캐릭터 · 플레이어 화면. 리메이크/안드로이드 세이브는 JSON 이라 읽을 것이 없다.
- 도구 앱 세계지도(원본 게임 화면 OCR + 도시 DB) 와 그 딸린 창(발견물 고치기 · 도서관 책 목록 · 지도 색표), DB 표 보기.
- 이미지 · 동영상 줄이기, 선박 등록(PC 파일을 가져오는 일), PC 파일 고르기 창(안드로이드에서는 「고를 수 없음」).
