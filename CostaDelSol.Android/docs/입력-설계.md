# 안드로이드판 입력 설계 노트

참고한 것: Kairo98(안드로이드 PC-98 에뮬레이터, https://github.com/MrJackSpade/Kairo98)
과 그 공용 프런트엔드 Kairo(https://github.com/MrJackSpade/Kairo, `frontend/` 의 Kotlin 코드).
이 판의 패드·터치 조작은 Kairo 의 구조를 본뜬다.

## 1. Kairo 입력 구조 요약

### 두 단계 매핑 — 실제 버튼 → 표준 컨트롤 → 동작
- **1단계(PhysicalControllerBindings)**: 안드로이드 입력을 기기와 무관한 표준 컨트롤 이름으로 바꾼다.
  - 표준 컨트롤 23개: `up down left right a b x y l1 r1 l2 r2 start select menu`
    `lsup lsdown lsleft lsright rsup rsdown rsleft rsright`
  - 입력 이름 꼴: `button:96`(키코드) · `axis:0:+`(축과 방향) · `hat:15:-`(HAT 축)
  - 기본표: 십자키는 `KEYCODE_DPAD_*` 와 `hat:AXIS_HAT_X/Y` 둘 다 up/down/left/right 로,
    왼스틱 `AXIS_X/Y` → ls*, 오른스틱 `AXIS_Z/RZ` → rs*, 트리거 축 `AXIS_LTRIGGER/RTRIGGER` → l2/r2,
    `BUTTON_MODE` → menu.
- **2단계(ControllerBinding)**: 표준 컨트롤 하나가 무엇을 할지.
  - `keys`(게임 키 여럿을 동시에 = 조합), `joystick`, `mouse`(커서 이동·왼/오른 버튼, 속도 배율),
    `action`(앱 동작: menu · pause · restart · exit · fastForward), `cycleKeys`(키 순환).
  - **키 순환**: L1/R1, L2/R2, 십자키 좌/우 짝에 키 목록을 걸면 누를 때마다 앞/뒤 키를 차례로 보낸다.
- 화면 단추(OnScreenControls)도 **같은 표준 컨트롤**을 누른다 → 패드와 터치가 한 매핑을 같이 쓴다.

### 겹(층) 매핑 — ControllerDefaults.cascade
- 아래부터: 시스템 기본(카탈로그) → 사용자 전체 설정 → 게임별 카탈로그 → 사용자 게임별 설정.
- 위 겹은 바꾼 것만 적는다. 명시적 null = 그 입력을 비운다. "기본값으로"는 겹 하나를 지우면 된다.

### 컨트롤러 감지 — ControllerConfiguration
- 붙은 기기를 훑어 **스틱 있음 / 스틱 없음** 레이아웃을 고른다(자동 · 강제 선택).
  - 스틱 판정: `getMotionRange(AXIS_X/Y)` 의 min<0<max, 오른스틱은 Z/RZ 또는 RX/RY.
  - 외장 패드를 내장보다 먼저, 지난번 기기를 먼저.
- 레이아웃마다 매핑과 화면 단추 배치를 따로 둔다.
- 기기 연결·해제를 듣고(ControllerDeviceMonitor) 자동이면 따라 바꾼다. 게임 중에는 고정.

### 입력 처리 — GamepadMapper
- 누른 것을 "주인(owner)" 문자열(`gamepad:기기:입력`, `onscreen:...`)로 들고, 같은 동작을 여럿이 누르면
  모두 뗄 때 뗀다(참조 셈). 기기가 빠지면 그 기기 것을 다 뗀다.
- 축 데드존 기본 0.10(설정 0.10~0.90), 누름은 데드존 이상, 뗌은 데드존의 절반 이하(떨림 방지 히스테리시스).
- 스틱이 마우스 이동에 걸리면 기울기만큼 비례 속도(초당 480, 16ms 틱).

### 버튼 잡기 — PhysicalInputCapture / KeyMappingMode
- 버튼은 `ACTION_DOWN` 첫 번만. 축은 처음 값을 기준선으로 잡고 **0.75 이상 움직여야** 잡는다
  (늘 눌려 있는 트리거·쏠린 스틱 오인 방지). 트리거는 + 쪽만.
- 매핑 화면: 키를 누른 뒤 붙일 패드 버튼을 누른다. 대기 중인 키를 다시 누르면 그 키에 붙은 버튼을 다 지운다.
  **메뉴 버튼은 매핑할 수 없다**(늘 메뉴를 연다).

### 화면 단추 — OnScreenControls
- 표시: **자동(패드가 붙으면 숨김) / 늘 보임 / 늘 숨김**.
- 십자키 모양: 네 단추(손가락이 어느 화살표에 닿든 넷이 같이 조종) 또는 **둥근 8방향 패드**(대각선 = 두 방향).
- 보일 단추를 고르고, **끌어서 자리 옮기기**(화면 비율 좌표로 저장). 세로/가로, 스틱 있음/없음마다 따로 저장.
- 기본 크기: 단추 54dp, 8방향 패드 148dp, 스틱 72~120dp. 반투명 둥근 단추.
- 가로 기본 자리(가로·세로 비율): 십자키 왼쪽 아래(.16,.75), A·B·X·Y 다이아몬드 오른쪽 아래
  (A .88,.82 · B .94,.74 · X .82,.74 · Y .88,.66), Start/Select 아래 가운데, Menu 위 가운데.

### 메뉴로 가는 길
- 안드로이드 뒤로 · **왼쪽 가장자리 쓸기** · 패드 메뉴(Mode) 버튼 → 게임 메뉴(저장 상태, 설정, 다시 시작, 종료).
- 오른쪽 가장자리 쓸기 → 화면 키보드.
- 메뉴 안에서는 HAT 축도 방향키처럼 먹고, 누르고 있으면 반복된다(DpadMotionNavigation).
- 앱 동작: 메뉴 열기, 일시정지/재개, 누르는 동안 빨리 감기, 다시 시작, 종료.

### 터치 입력 모드
- 자동 / 키보드 / 마우스. 마우스면 **터치패드**(끌면 이동, 톡 치면 클릭, 길게 누르면 끌기) 또는 직접 터치.

## 2. 이 게임에 옮길 것

Kairo 의 "PC-98 키" 자리에 이 게임의 **동작**(PC 판 단축키를 뜻으로 묶은 것)을 놓는다.

| 동작 | PC 판 원래 키 |
|---|---|
| 방향(조타·고르기) | 숫자판 1~9, 방향키, 커서 |
| 결정 | 엔터·스페이스·왼쪽 클릭 |
| 취소/닫기 | ESC·오른쪽 클릭(대화상자) |
| 닻 | 5·지도 왼쪽 클릭 |
| 커맨드 창 | 0·오른쪽 클릭 |
| 도시정보 | 상단 띠 오른쪽 클릭 |
| 저장 | V |
| 발견물 지도 | D |
| 확대·축소 | 휠 |
| 이전/다음 쪽 | PgUp·PgDn(해전 전황, 미궁 층, 연대기) |
| 숫자 1~3 | 일기토·교역소 고르기 |
| 다시 읽기 | F5(교역소) |

- 매핑 겹: 기본 → 사용자 전체 → **화면별**(바다·도시·해전·미니게임) → 사용자 화면별. Kairo 의 "게임별" 자리를 "화면별"로 쓴다.
- 키 순환은 도시 건물 고르기(PC 의 방향키 순환)에 그대로 맞는다 — L1/R1.
- 오른스틱 = 마우스 커서(지도·건물·해전 칸을 찍을 때), R1/L1 = 왼/오른 클릭으로 쓸 수 있다.
- 가로로 긴 화면은 원본 4:3 판 양옆에 화면 단추를 둔다.

## 3. 정한 기본 배치 (2026-10-31, 사용자 결정)

| 버튼 | 기본 | 비고 |
|---|---|---|
| R스틱 | 배 이동(8방향) | 기울인 쪽이 숫자판 1~9 키가 된다 |
| L스틱 | 마우스 이동 | 스틱은 이 둘 가운데 하나만 고른다 |
| R3 | 5 (닻) | |
| L3 | 가상 키보드 | |
| L1 / R1 | 마우스 오른쪽 / 왼쪽 클릭 | |
| L2 / R2 | PgUp / PgDn | 추천해서 정함 |
| Select | D (발견물 지도) | |
| Start | 0 (커맨드) | 한 번 더 누르거나 ESC 로 닫힌다. 커맨드에 저장·네비게이션 추가 |
| Menu | 앱 메뉴 | 바꿀 수 없다. 차림표 · 버튼 매핑 · 화면 패드 · 가상 키보드 · 단축키 목록 |
| A / B | ESC / 엔터 | |
| X / Y | 스페이스 / V | 추천해서 정함 |
| 십자키 | 방향키 | |

- 터치: 톡 = 왼쪽 클릭, 길게 = 오른쪽 클릭, 두 손가락 = 확대·축소, 끌기 = 마우스 끌기.
- 화면 패드(게임패드 없는 기기): 보이기(자동/늘/숨김), 단추마다 보이기·숨기기, 끌어서 옮기기, 크기(전체·단추별).
- 버튼 매핑 화면 오른쪽 위에 「대항해시대3 단축키」 단추.
- 도구 앱(Editor.exe, 세이브 편집기)은 따로 된 WPF 앱 약 1만 2천 줄이라 메뉴에 바로 못 넣는다 — 필요한 화면만 골라 나중에.
